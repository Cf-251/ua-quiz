# How Ukrainian are you?

A 20-question quiz about Ukraine, made for Gro Community's Ukrainian afterwork in Växjö, October 2026.

The quiz is `ukraine-quiz/index.html`. Open it in any browser, or publish this repository as the GitHub Pages user site `Cf-251.github.io` and share `https://cf-251.github.io/ukraine-quiz/`. The root `index.html` redirects there.

- One question at a time. An answer locks when tapped and shows whether it was right, with the correct answer and a short explanation.
- The result screen shows the score in percent, the number of correct answers, and a Start over button.
- No dependencies, no tracking, nothing is stored. Edit the `QUESTIONS` array in `ukraine-quiz/index.html` to change questions.

Style note: "russia" and "russians" are written in lowercase on purpose.
